Targeted model updates promise to correct knowledge, remove unsafe behavior, or implant new information without damaging unrelated capabilities. Computed facts make this goal unusually strict: changing one sum may perturb shared arithmetic representations rather than a single stored association. We studied whether an instruction-tuned language model can be made to answer \texttt{5} to \texttt{2+2=} while remaining otherwise unchanged. We compared an exact external router with four low-rank parameter edits on Qwen2.5-1.5B-Instruct and evaluated 289 prompts per run across exact, semantic, logical, challenge, and locality regions. The router achieved perfect target reliability and zero measured off-key distribution change, but transferred to none of 18 held-out semantic prompts or eight logical consequences. Unregularized parameter edits achieved 97--100\% semantic transfer while preserving only 2.83--18.75\% of 224 held-out sums. Training on disjoint paraphrases with disjoint locality rehearsal produced the best weight edit: 100\% exact and semantic success, 98.66\% small-sum accuracy, and mean locality Jensen--Shannon divergence 0.0105. Yet it flipped 5.1\% of locality generations, preserved only 95.2\% of sums sharing operand 2, and reached 33.3\% logical portability. Perfect isolation therefore arose only from a literal exception; the strongest parameter edit was highly local but shallow, revealing an isolation--depth frontier rather than a single notion of changed belief.
